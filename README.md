## Overview

This repository contains the code, datasets, and analysis scripts accompanying the paper:

> Patterns of Priming in Production: Lexical, Semantic and Structural Alignment in Language Model Generation

The paper was accepted to **Findings of the Association for Computational Linguistics: EMNLP 2026**, with 14.3% acceptance rate.

The repository provides all resources necessary to reproduce the experiments and analyses presented in the paper, including data preprocessing, experimental pipelines, statistical analyses, and figure generation.
